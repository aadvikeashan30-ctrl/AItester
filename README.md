# AItester — AI Employee Monitoring & Productivity

A privacy-first, consent-based employee productivity assistant.

## Components

- **Live Monitoring Dashboard** (`dashboard.html`) — single-page vanilla HTML/CSS/JS dashboard with KPIs, employee table, alerts, and a per-employee AI Manager Report drill-down. Open the file directly in a browser to demo.

Configuration & Database Schema

Database Migration Scripts (SQL)

-- Users Table CREATE TABLE users ( employee_id VARCHAR(10) PRIMARY KEY, name VARCHAR(100) NOT NULL, email VARCHAR(150) UNIQUE NOT NULL, phone VARCHAR(20) NOT NULL, role ENUM('Employee', 'HR') DEFAULT 'Employee', date_of_joining DATE NOT NULL, active_status BOOLEAN DEFAULT TRUE, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ); -- Leave Allotment Table CREATE TABLE leave_allotment ( id INT AUTO_INCREMENT PRIMARY KEY, employee_id VARCHAR(10) NOT NULL, month_year VARCHAR(7) NOT NULL, total_allotted INT DEFAULT 2, used_leaves INT DEFAULT 0, remaining_balance INT DEFAULT 2, FOREIGN KEY (employee_id) REFERENCES users(employee_id), UNIQUE KEY unique_emp_month (employee_id, month_year) ); -- Leave Requests Table CREATE TABLE leave_requests ( request_id VARCHAR(20) PRIMARY KEY, employee_id VARCHAR(10) NOT NULL, leave_date DATE NOT NULL, reason TEXT NOT NULL, status ENUM('Pending', 'Approved', 'Rejected') DEFAULT 'Pending', whatsapp_message_id VARCHAR(50), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, FOREIGN KEY (employee_id) REFERENCES users(employee_id) );

API Endpoints

POST /api/leave/apply - Submit leave request GET /api/leave/balance/:empId - Get leave balance GET /api/leave/requests/:empId - Get employee requests PUT /api/leave/approve/:reqId - Approve request (HR only) PUT /api/leave/reject/:reqId - Reject request (HR only) POST /api/whatsapp/webhook - Inbound WhatsApp webhook (secured) POST /api/whatsapp/status - Message status callback POST /api/cron/monthly-allot - Trigger monthly allotment POST /api/cron/hr-reminder - Trigger 48hr reminder check

Automated Cron Jobs

Monthly Leave Allotment

Schedule: 0 0 1 * * (1st of every month at midnight)

Action: Credits 2 Casual Leaves to all active employees. Resets previous month balance (no carry forward).

HR Reminder (48hr Timeout)

Schedule: 0 * * * * (Every hour)

Action: Sends WhatsApp reminder to HR for any pending request older than 48 hours.
